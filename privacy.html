隱私權政策

更新日期：2026 年 11 月 6 日

本政策說明 Outlook Google Calendar Sync 本機程式及本說明網站如何處理資料。工具由 Teng-Xiang-Yu 維護，供帳號擁有者自行使用。

1. 存取的資料

程式讀取使用者指定 Exchange 行事曆範圍內的活動識別碼、標題、起訖時間、全天性質、地點、說明、Teams 連結、回覆狀態與私人及取消標記。它也讀取指定 Google 主行事曆的活動與同步標記，用於比對與驗證副本。

Google 權限為 https://www.googleapis.com/auth/calendar.events.owned，可讀寫使用者擁有的行事曆活動；本工具的實作僅操作使用者指定的主行事曆，不要求 Gmail、聯絡人或 Drive 權限。

2. 用途與傳輸

活動資料僅用於使用者要求的單向同步、差異比對、防止重複及結果驗證。使用者指定的來源活動欄位會經 HTTPS 傳送至 Google Calendar，並成為其帳號中的副本。私人活動不將地點、說明或 Teams 連結寫入 Google 副本。

同步程式不使用資料投放廣告、販售資料或訓練 AI 模型，也不呼叫生成式 AI。除使用者指定的 Exchange 與 Google Calendar 服務外，同步程式不將活動資料傳送到其他應用後端。本網站不接收活動資料。

3. 本機保存與存取

Google OAuth 存取及更新憑證以 Windows DPAPI 加密後保存在本機，綁定目前 Windows 使用者；程式不儲存 Google 或 Exchange 密碼。OAuth 桌面用戶端設定與同步設定也保存在本機。

本機來源快取、執行記錄與報告可能包含所讀取活動的詳細資訊與識別碼。這些資料不隨公開說明網站發布，會保留至使用者自行刪除；同一 Windows 帳號下具有檔案存取能力的程式可能讀取它們。

4. 控制、撤銷與刪除

使用者可停用 Windows 排程，並在 Google 帳戶的第三方連線設定撤銷授權。也可自行刪除本機憑證、設定、快取與報告。

撤銷授權或刪除本機檔案不會自動刪除 Google Calendar 中已建立的副本；使用者可在其行事曆中自行移除副本。本工具不會因停止使用而自動清空行事曆。

5. 公開說明網站

本站為 GitHub Pages 靜態說明頁，沒有帳號登入、會議上傳、廣告或分析追蹤程式。網站主機供應商 GitHub 可能依其政策處理 IP 位址等連線記錄，詳見 GitHub 隱私權聲明。

6. Google 使用者資料的有限使用

本工具使用及傳輸從 Google API 收到的資訊，將遵守 Google API Services User Data Policy，包括 Limited Use 要求。

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

7. 問題與政策更新

如對資料處理方式有疑問，請透過維護者的 GitHub 頁面聯絡。公開回報時請勿附上會議內容或授權憑證。資料處理方式若有調整，本頁會更新日期與相關說明。
