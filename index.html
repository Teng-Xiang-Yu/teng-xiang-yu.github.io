Outlook Google Calendar Sync 是供帳號擁有者自行使用的 Windows 本機工具，將其指定的 Exchange 行事曆活動單向複製到 Google 主行事曆。

Exchange 行事曆→Windows 本機程式→Google 主行事曆

如何運作

程式在使用者的 Windows 電腦上執行，讀取當天起共 21 天的活動，依使用者設定的時間同步標題、起訖時間、全天性質、地點、純文字說明與 Teams 加入連結。週期會議的每次活動會各自建立副本。

只有帶有同步標記的副本會被持續更新或刪除。標題與起訖時間完全相同的既有活動，可以依設定納入管理；其他未標記活動維持原狀。

以使用者授權為前提

Google 存取透過官方 OAuth 同意畫面授權。程式申請 calendar.events.owned 活動權限，該權限涵蓋使用者擁有的行事曆；本工具實作固定操作使用者指定的 Google 主行事曆。它不需要讀取 Gmail、聯絡人或 Google Drive。

Exchange 讀取使用目前 Windows 登入身分，不更動來源活動。私人會議的副本僅包含標題、時間及全天性質與同步標記；已拒絕或取消的會議不納入有效副本。同步不加入與會者、不建立 Google Meet，也不設定提醒。

本網站的用途

這裡只提供程式與資料處理方式的公開說明，不提供登入或同步操作，也不接收會議資料、密碼或授權憑證。同步程式、設定與執行報告留在使用者的電腦上。

A personal, locally run Windows utility for one-way Exchange-to-Google Calendar synchronization. This website contains documentation only; it does not process calendar data or offer a public sign-up service.
